## 🧭 About

I'm a **42 Paris (École 42)** graduate and a Fullstack Engineer based in Paris. I like taking a blank repo all the way to a real product in production — and I care as much about the **architecture** behind it as the **interface** in front of it.

In my first year shipping professionally I've built a wide range of products: cultural platforms like *Nemausus* (3D encyclopedias and interactive scavenger hunts), multi-tenant SaaS, and CRM / back-office systems handling cross-branch operations. I work **architecture- and security-first**, on foundations built around **OWASP best practices**, and I lean on AI tooling to ship faster without cutting corners.

```yaml
role:      Fullstack Engineer
location:  Paris, France · available worldwide
focus:     Architecture · Web security · UI/UX · Systems that scale
principles:
  - Security first     # OWASP-aware decisions baked in, not bolted on
  - Performance        # Lighthouse 100 is the floor, not the goal
  - UI craftsmanship   # Every shadow, radius and easing chosen with intent
```
